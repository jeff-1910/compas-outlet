# Compas Outlet

Catalogo web de **Compas Outlet**, tienda de articulos varios en Costa Rica:
muebles, hogar, cocina, electronicos, ropa y calzado a precio de outlet.

Los clientes arman su pedido en el catalogo y lo envian por WhatsApp.

- `index.html` — la tienda
- `admin.html` — panel para cargar articulos
- `js/config.js` — datos del negocio (WhatsApp, redes, moneda)
- `js/productos.js` — el catalogo

Instrucciones completas de uso en [LEEME.md](LEEME.md).

Sitio estatico: no necesita compilacion ni servidor. Se abre con doble clic en
`index.html`.
